About Crucible

Crucible is the Molecular Foundry's common data platform. Staff and users use it to acquire, annotate, find, and analyze the data collected on Foundry instruments, and to make that data ready for sharing, reuse, and machine learning.

It combines software tools, automated workflows, and shared metadata schemas, so data from different instruments can be searched and analyzed together. The name refers to the melting pot used in a foundry; it was coined by Stephen Whitelam.

Open Source Software

Crucible's workflows and infrastructure are developed in the open on GitHub.

nano-crucible

FAIR Data

We aim to make data from the Foundry FAIR: findable, accessible, interoperable, and reusable.

Findable

Every record has a unique identifier (MFID) and appears in a searchable catalog.

Accessible

Data and workflows are reachable from the web and a REST API. Access controls keep user data private until publication.

Interoperable

Metadata is stored and served as standard JSON.

Reusable

Historical data stays available, so collections can be combined and reused.
